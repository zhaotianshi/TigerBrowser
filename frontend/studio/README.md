# TigerBrowser Web Console

基于 Vue 3 + TypeScript + Vite + Pinia 构建的 Camoufox 团队控制台与独立原生远程操作界面。

这是 Studio 唯一的网页前端。构建产物随 Python wheel 和桌面包分发，服务固定读取包内 Vite 清单；源码检出须先构建，缺失资产时服务拒绝启动。

## 架构与对齐

接口契约见 [`docs/studio-team-api.md`](../../docs/studio-team-api.md)，服务启动与部署见 [`docs/studio-team-service.md`](../../docs/studio-team-service.md)：

- **技术栈**：Vue 3 (Composition API / `<script setup>`) + TypeScript + Vite + Pinia + Vue Router + Lucide Icons。
- **视觉系统**：深蓝灰背景（`#0B1220`）、分层卡片（`#152238`）与薄荷绿强调色（`#5BE2C4`）；同源中文字体，正文及环境名称 16px、按钮与表头 14px、辅助文字 13px。共享字号与颜色变量定义于 `src/assets/base.css`，支持键盘焦点、减少动态效果和窄屏布局。
- **独立路由**：使用 hash 路由（`createWebHashHistory`），天然兼容现有服务的同源静态路由约束以及 `/#remote=<UUID>` 独立远程窗口直达入口。
- **状态流转**：通过 `/team/v1/events` 维持单应用级 WebSocket 长连接同步，全界面响应式更新，避免多卡片重复开销。

## 页面与功能模块

“API 密钥”页面向管理员和操作员提供一次性连接文件下载、环境/来源 IP/有效期限制与吊销。
密钥仅保存在当前页面内存中，退出登录或关闭页面即清除；只读成员不能进入该页。

环境编辑页可选择精确内核版本，并保留当前未安装的历史值。设置页的默认内核只用于新建环境，
更换环境内核会重建身份并保留网站数据；团队启动不读取旧的全局可执行文件设置。

在桌面客户端内打开时，`src/desktop/bridge.ts` 检测到本机桥后才显示桌面专属内容；普通浏览器中这些按钮和页面不存在。
"本机启动"先以登录会话向服务器签出，再把租约交给本机桥下载并启动，关闭浏览器后自动签回；租约未能交给本机桥时立即放弃。
环境列表合并本机状态与服务器的 `checked_out`：在其他设备运行的环境显示持有成员和设备，管理员可强制解锁。
"本机"页面保存本机并发上限（只存于本机缓存）、列出待下载或待签回的环境与失效副本。
HTTP 连接时顶部明文提示常驻，不能关闭。
"客户端下载"页列出服务器 `--client-root` 提供的各平台安装包及 SHA-256；在桌面中还显示本客户端版本，
有兼容的新版本时由本机桥下载、校验并安装。客户端与服务器协议不兼容时，控制台只显示此页。

1. **浏览器环境 (Profiles)**
   - 顶部统计卡（全部环境、正在运行、已绑定代理）
   - 多维度筛选（名称/标签/备注搜索、分组下拉、显示归档）
   - 七个信息/操作列（名称、状态、系统/语言、代理、分组/标签、上次启动时间、操作），另有选择框；桌面操作列固定在右侧，中等宽度可在表格内横向滚动，手机窄屏切换为带名称与操作的环境卡片
   - 每行直接提供启动、无头启动、停止，无需先勾选；运行中的远程环境保留操作窗口入口。不可用按钮显示禁用原因，请求期间防止同一环境重复提交
   - 管理操作栏常驻（远程窗口、编辑、复制、归档/恢复、删除、详情、管理员 Cookie 导入导出），未选择时置灰；桌面中保留本机启动与停止本机，管理员仍可对符合条件的签出环境强制解锁。选中多个环境后增加批量启动、批量无头启动与批量停止；行内与批量启停共用 `stores/profiles.ts` 的权限、服务能力、签出及运行状态检查
   - 远程启动统一使用固定 KasmVNC 组件；无后端选择器，组件缺失或校验失败时明确拒绝服务启动
   - 单击行空白处选行、Ctrl/Cmd 多选、Shift 范围连续选、复选框多选；点击环境名称或双击行打开详情，行内操作不改变勾选项
   - 四页签编辑弹窗（基础信息、网络与系统、高级指纹策略、启动行为）与修订号冲突校验
   - 时区按地区分组并可搜索，选项来自服务器数据库；旧别名保留，自动模式保存为空字符串；绑定代理显示最近探测的出口时区
2. **代理资源 (Proxies)**
   - 列表展示、状态与关联环境数
   - 支持 HTTP、HTTPS、SOCKS5
   - 一键解析代理地址
   - 批量导入与订阅解析预览/导入有界 Task
   - 节点网络连通性探针（出口 IP、时区、延迟）
3. **活动记录 (Activity)**
   - 工作区最近 200 条审计与操作日志，四列桌面同款表格
4. **工作区设置 (Settings)**
   - 浏览器可执行文件与最大并发数配置
   - 运行中可调整不低于活动运行数的并发上限
   - 官方内核四平台缓存与删除、新环境默认内核
   - 工作区整体配置（JSON）导出与停止屏障导入
5. **团队管理 (Team)**
   - 成员增删改查、停用/启用、密码重置
   - 角色上限（Operator / Viewer）与直接环境授权 (`view`, `watch`, `operate`)
   - 成员组（组成员管理、组授权合并）与管理审计日志
6. **服务状态 (Status)**
   - 真实执行机运行指标：活动运行数、最大容量、挂起命令、磁盘剩余空间、图形会话与安全屏障
   - 严格遵循 `ci/tribal-rules.yml`，绝不虚构 CPU/内存伪造数据
7. **独立原生远程窗口 (`/#remote=<profile_id>`)**
   - 占满视口的全屏沉浸式布局，无管理侧栏干扰
   - 自主鉴权恢复（401 内联弹出登录，不跳出原链接）
   - 连接信息校验（按原因码反馈 `watch_required`, `not_running`, `recovery_required` 等）
   - NativeRemoteController 模块化输入控制器（代次 generation、严格递增序号 sequence、物理键白名单过滤、IME 组合键防卡键、失焦释放）
   - 100% 原始大小与适应窗口缩放切换
   - 中文/长文本输入发送栏（最多 1 MiB UTF-8，保留换行和空格，不截断；普通窗口和全屏均可用）
   - Linux 选中内容/环境剪贴板一键复制至本机，权限拒绝时可从预览复制
   - 文件交换面板（上传限制 8MB，下载列表拉取）
   - 远程页面仅解码 KasmVNC 增量画面；保留控制权、中文输入、剪贴板与文件交换工具

KasmVNC 入口由 `/profiles/{id}/remote` 返回 `transport: "kasmvnc"` 和协议版本 2。
控制连接先以 CSRF 建立逻辑观看会话，再将返回的 `viewer_id` 与 CSRF 通过画面连接
的首条消息关联。画面连接收到服务端 ready、安装解码器后才回复 ready 并开始二进制
RFB。客户端仅加载团队服务同源提供的固定 `/kasm-client.js` 和 `/kasm-client/rfb.js`，
不接触上游端口或认证凭据。解码器仅显示画面，输入继续使用原有成员控制网关；
客户端缩放不修改已保存的环境分辨率。任一连接关闭都会清理两条连接、输入队列和
解码器；重新连接保持只读，需要再次申请控制。关闭远程窗口不停止浏览器。

环境启动按钮与状态均有加载动画。登录和路由切换会同步管理状态连接，启动结果
自动更新环境列表；申请控制与全屏为独立操作。
远程输入复用 `src/components/remote/remote-input.ts` 的移动合并
逻辑。只合并尚未编号的连续移动，保留最后位置；点击和按键前保序发送，释放或失去
控制后清除待发移动。该模块随生产构建纳入同源制品，
无需另行复制文件或增加运行服务。

## 本地开发与构建

进入 `frontend/studio/` 目录：

```bash
# 安装依赖
npm ci

# 运行本地开发服务器 (默认端口 5173，自动代理 /team/v1 到 127.0.0.1:8766)
npm run dev

# 运行单元测试
npm test

# 生产构建，输出到 ../../pythonlib/camoufox/studio/team/web/
npm run build
```

后端默认监听 `http://127.0.0.1:8766`。使用其他地址时，在本地 `.env.local` 设置
`VITE_TEAM_ORIGIN`；该文件不提交到 Git。开发代理会匹配后端的 Host、Origin 与
WebSocket 校验，账号初始化步骤见[团队服务的安装和首次使用](../../docs/studio-team-service.md#安装和首次使用)。
KasmVNC 解码器由本工程的 `public/` 提供，无需放宽后端跨域或 CSP。

`pythonlib/camoufox/studio/team/web/` 是不进 Git 的构建目录。构建后在仓库根目录
启动已安装团队依赖的 `studio-team` 即可；`--web-root` 已移除。Poetry 显式将该目录
加入 wheel 和 sdist，PyInstaller 使用同一产物。CI 构建一次并向各 Python/打包任务传递
包含隐藏 `.vite/manifest.json` 的完整资源，验证真实 wheel 中的资产。
`vite preview` 仅用于本地预览，完整部署仍需浏览器验收。

## 原生诊断采集器与回归测试

`src/diagnostics/collectors.ts` 是原生诊断的唯一采集器源码。修改后在本目录运行
`npm run build:probe`，生成 Python 包中的 `studio/team/probe.js`；产物首行记录规范
LF 源码的 SHA-256，Python 测试检查二者一致。esbuild 固定为 0.25.12，避免依赖已删除的
浏览器测试项目。此采集器用于显式诊断，不作为日常启动门槛。

旧控制台的适用行为现由 Vue 回归覆盖，原控制台源码和测试已移除：

| 行为 | 回归 |
| --- | --- |
| HTTP 下安全随机请求 ID | `src/__tests__/api.test.ts` |
| 重连时刷新 CSRF、断网只读重试、登出与旧连接的迟到响应 | `src/__tests__/session-events.test.ts` |
| 输入合并、最终位置、连续序号、释放与断开清理 | `src/__tests__/remote-controller.test.ts` |
| 全屏、滚动坐标、IME 修饰键释放、可恢复错误与失焦 | `src/__tests__/remote-view.test.ts` |
| 操作窗口即时打开、清除 opener | `src/__tests__/profile-window.test.ts` |
| Kasm 双通道、只读门禁、失败与迟到解码器清理 | `src/__tests__/kasm-remote.test.ts` |
| 无后端选择的远程与批量启动请求 | `src/__tests__/profile-launch.test.ts` |
| 行内/批量启停、权限和签出门禁、独立目标及防重复提交 | `src/__tests__/profile-actions.test.ts` |

全屏和申请控制保留为独立按钮；普通窗口同样可发送和复制文本。真实 KasmVNC、
多观看者、持续输入与解码资源检查见 `service-tester/README.md`；单元测试不代替原生验收。
