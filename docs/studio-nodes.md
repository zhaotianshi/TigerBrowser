# 代理配置

TigerBrowser 支持 HTTP、HTTPS 和 SOCKS5。可给每个浏览器环境选择一个已保存的代理，也可以让环境使用系统网络。选定代理的连通性检查失败时，环境会停止启动。

在“代理资源”中选择协议，填写主机、端口和可选的用户名与密码。“测试代理”会检查出口与时区。批量导入每行填写一个地址，例如：

```text
http://proxy.example:8080
https://user:example%40password@proxy.example:443
socks5://proxy.example:1080
```

地址需显式指定端口。URL 中的凭据包含保留字符时使用百分号编码。所有行先校验，任一行不支持时整个批次不写入。

密码保存在执行环境的系统凭据服务中，配置导出只包含代理的名称、端点及用户名等非密码数据。旧版配置中的节点或链式代理需要先替换为有效的 HTTP、HTTPS 或 SOCKS5 代理地址。
